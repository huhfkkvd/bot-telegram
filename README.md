# ربات فروش نمایندگی (تلگرام)

ربات ساده و کامل فروش نمایندگی/پنل با پرداخت کارت‌به‌کارت، تأیید دستی ادمین و تحویل خودکار به مشتری.

## امکانات
- نمایش پلن‌ها و انتخاب توسط کاربر
- نمایش شماره کارت و دریافت رسید (عکس/فایل)
- ارسال سفارش جدید به ادمین همراه با دکمه‌های ✅ تأیید / ❌ رد
- بعد از تأیید، ادمین اطلاعات پنل رو می‌فرسته و ربات خودکار به مشتری تحویل می‌ده
- بخش «سفارش‌های من» برای کاربر (وضعیت + اطلاعات پنل‌های تحویل‌شده)
- ذخیره‌سازی با SQLite (بدون نیاز به دیتابیس جدا)

## اجرای محلی (تست قبل از آپلود)
```bash
pip install -r requirements.txt
cp .env.example .env   # و مقادیر رو پر کنید
python bot.py
```

## دیپلوی روی Railway (مرحله به مرحله)

1. یک بات جدید در تلگرام از [@BotFather](https://t.me/BotFather) بسازید و توکن رو کپی کنید.
2. آیدی عددی خودتون رو از [@userinfobot](https://t.me/userinfobot) بگیرید (این آیدی ادمین شماست).
3. این پوشه رو در یک ریپازیتوری گیت‌هاب آپلود کنید (یا مستقیم zip رو در Railway آپلود کنید).
4. در [railway.app](https://railway.app):
   - **New Project → Deploy from GitHub repo** رو بزنید و ریپازیتوری رو انتخاب کنید.
   - Railway به‌طور خودکار `Dockerfile` رو تشخیص میده و بیلد می‌کنه.
5. در تب **Variables** پروژه، این متغیرها رو اضافه کنید:
   | Key | Value |
   |---|---|
   | `BOT_TOKEN` | توکن گرفته‌شده از BotFather |
   | `ADMIN_IDS` | آیدی عددی ادمین(ها) - با کاما جدا کنید |
   | `CARD_NUMBER` | شماره کارت برای پرداخت |
   | `CARD_HOLDER` | نام صاحب کارت |
   | `DB_PATH` | `/data/bot.db` (توضیح در مرحله بعد) |
   | `BRAND_NAME` | نام برند (مثلاً X4G) |
   | `SUPPORT_USERNAME` | آیدی تلگرام پشتیبانی بدون @ (مثلاً SuppX4G) |
   | `REFERRAL_REQUIRED_COUNT` | تعداد دعوت موفق لازم برای هدیه (پیش‌فرض 3) |
   | `REFERRAL_REWARD_VOLUME` | حجم پنل هدیه به گیگ (پیش‌فرض 50) |
6. **مهم — ماندگاری دیتابیس:** روی Railway فایل‌سیستم بین دیپلوی‌ها ری‌ست میشه. برای اینکه سفارش‌ها پاک نشن:
   - در تب **Volumes** یک Volume جدید بسازید و آن رو در مسیر `/data` مانت (mount) کنید.
   - مطمئن شوید متغیر `DB_PATH=/data/bot.db` تنظیم شده باشه.
7. بعد از دیپلوی، لاگ‌ها رو چک کنید؛ اگر پیام خطا نبود، ربات آماده‌ست. به تلگرام برید و `/start` بزنید.

## منوی اصلی
- 🛍 خرید سرویس
- 🖥 سرویس‌های من (لیست سفارش‌ها؛ روی هرکدوم کلیک کنید تا جزئیات و کانفیگش نشون داده بشه)
- 💰 کیف پول (فعلاً نمایشی - موجودی 0 تومان، آماده توسعه در آینده)
- 💬 پشتیبانی (دکمه‌ای که مستقیم پی‌وی ادمین رو باز می‌کنه)
- 🤝 دعوت دوستان (سیستم رفرال)
- 🛠 مدیریت ربات (فقط برای ادمین‌ها نمایش داده میشه)

## مسیر خرید
`🛍 خرید سرویس` → انتخاب سرویس (گیمینگ / مولتی لوکیشن) → انتخاب تعرفه → نمایش خلاصه سفارش + شماره کارت با دو دکمه «📤 ارسال رسید» و «🔙 بازگشت» → با زدن «ارسال رسید»، ربات منتظر عکس/فایل رسید می‌مونه.
همه‌جا دکمه «🔙 بازگشت» برای برگشت به مرحله قبل وجود داره.

## بخش سرویس‌های من
با زدن «🖥 سرویس‌های من» لیست سفارش‌ها به‌صورت دکمه (با آیکون وضعیت) نشون داده میشه. با کلیک روی هر سفارش، جزئیات کامل (پلن، قیمت، وضعیت و در صورت تحویل، اطلاعات/کانفیگ سرویس) نمایش داده میشه و یک دکمه «🔙 بازگشت به لیست سرویس‌ها» هم وجود داره.

## بخش مدیریت ربات (فقط ادمین)
دکمه «🛠 مدیریت ربات» فقط برای آیدی‌های داخل `ADMIN_IDS` توی منوی اصلی نمایش داده میشه (با دستور `/admin` هم قابل دسترسیه). از این بخش می‌شه:
- **تعرفه‌های گیمینگ و مولتی لوکیشن**: تغییر قیمت هر تعرفه، فعال/غیرفعال کردن، افزودن تعرفه جدید (حجم/عنوان + قیمت دلخواه).
- **✉️ پیام خوش‌آمدگویی**: متن پیام `/start` رو کاملاً دلخواه تغییر بدید (تگ‌های ساده HTML مثل `<b>` پشتیبانی میشه).
- **🤝 تنظیمات رفرال**: تعداد دعوت موفق لازم برای دریافت هدیه، و حجم پنل هدیه (گیگ) رو هر زمان که خواستید عوض کنید؛ نیازی به تغییر Environment Variable یا ری‌دیپلوی نیست.

همه این تنظیمات داخل دیتابیس ذخیره می‌شن، پس با هر بار ری‌استارت شدن ربات از بین نمی‌رن (به شرطی که از Volume برای دیتابیس استفاده کرده باشید، طبق مرحله ۶ بالا).

## سیستم رفرال (دعوت دوستان)
هر کاربر یک لینک اختصاصی می‌گیره (`t.me/<bot>?start=ref_<user_id>`). وقتی کسی از این لینک وارد بشه و **خریدش توسط ادمین تحویل داده بشه**، به‌عنوان یک دعوت «موفق» ثبت می‌شه.
با رسیدن به تعداد مشخص (پیش‌فرض ۳ نفر) یک پنل رایگان (پیش‌فرض ۵۰ گیگ) با لوکیشن دلخواه به کاربر تعلق می‌گیره؛ کاربر از همون بخش «دعوت دوستان» لوکیشن رو انتخاب می‌کنه و سفارش رایگان به‌صورت خودکار برای ادمین ارسال میشه تا تحویل بده.
مقادیر قابل تنظیم در `config.py` یا Environment Variables: `REFERRAL_REQUIRED_COUNT` و `REFERRAL_REWARD_VOLUME`.

## نکته درباره دکمه پشتیبانی
آیدی پشتیبانی (`SUPPORT_USERNAME`) فقط داخل لینک دکمه قرار می‌گیره، نه در متن پیام - یعنی کاربر عادی آیدی رو در متن نمی‌بینه و فقط با زدن دکمه پی‌وی پشتیبانی باز میشه. توجه داشته باشید تلگرام به‌طور کامل امکان مخفی‌کردن آدرس لینک از کاربر فنی/کنجکاو رو نمی‌ده (مثلاً با نگه‌داشتن روی دکمه در بعضی کلاینت‌ها لینک نمایش داده میشه)، اما در حالت عادی استفاده، آیدی در متن پیام دیده نمی‌شه.

## نکته درباره رنگ دکمه‌ها
تلگرام (از طریق Bot API) اجازه تنظیم رنگ سفارشی برای دکمه‌های Reply Keyboard یا Inline رو نمی‌ده - رنگ دکمه‌ها بر اساس تم (Theme) کلاینت تلگرام کاربر تعیین میشه، نه توسط ربات. برای تمایز بصری از ایموجی و چیدمان دکمه‌ها استفاده شده.

## ویرایش پلن‌ها، برند و پشتیبانی
همه داخل فایل `config.py` هستند:
- `COUNTRIES`: لیست کشورها (کد + نام نمایشی)
- `VOLUMES`: لیست حجم‌ها بر حسب گیگابایت
- `BASE_PRICE` و `PRICE_STEP`: قیمت ۵۰ گیگ اول و مقدار افزایش قیمت به ازای هر پله بعدی (الان: شروع از ۱۰۰ تومان با پله‌های ۲۰۰۰ تومانی)
- `BRAND_NAME`: نام برند که در پیام خوش‌آمدگویی نمایش داده میشه
- `SUPPORT_USERNAME`: آیدی تلگرام پشتیبانی (بدون @)

## نکات مهم امنیتی
- توکن ربات و آیدی ادمین‌ها رو هیچ‌وقت داخل کد قرار ندید؛ همیشه از Environment Variables استفاده کنید (همونطور که در بالا انجام شده).
- فایل `.env` رو در گیت‌هاب آپلود نکنید (در `.gitignore` قرار داده شده).
- این ربات پرداخت رو به‌صورت **دستی** (تأیید توسط ادمین) مدیریت می‌کنه، یعنی درگاه پرداخت آنلاین نداره. اگر بعداً خواستید درگاه آنلاین (زرین‌پال و ...) اضافه کنید، بگید تا اون بخش رو هم اضافه کنم.
